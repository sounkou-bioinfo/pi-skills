# Bioinformatics technical names and technical verbs

This list gives technical names and technical verbs for bioinformatics text.
The list is an addition to the skill. It is not a part of the ASD-STE100 dictionary.
The `ste_check` tool accepts the words of this list.
Refer to `bioinformatics.md` for the rules.

Format: `WORD (part of speech) [other forms]`

Parts of speech: n = technical name, adj = technical name that is an adjective,
v = technical verb.

Rules for this list:
- Use a technical name only as a noun or an adjective.
- Use a technical verb only when no approved verb is sufficient.
- The plural of a technical name is also permitted.
- Add the technical names of your project in the same format.
